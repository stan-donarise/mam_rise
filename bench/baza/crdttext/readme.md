# $rise_bench_baza_crdttext

Обычная `$mol_textarea`, связанная с настоящим `$giper_baza_text.text()`.
Кнопка добавляет 500 нумерованных строк; повторная вставка сохраняет предыдущие.
Текст хранится локально в Гипербазе и открывается после F5. Сброс очищает тот же
CRDT-документ и текущие метрики, не удаляя другие данные браузера.

Время записи измеряется после подготовки Land до возврата CRDT-операции,
включая чтение итогового текста методом `text(next)`. Объём — полный текст
в UTF-16 code units (`String.length`), скорость — этот объём / время.
Это не число физических CRDT-операций и не скорость фонового сохранения на диск.
Отрисовка textarea также не входит в показанное время.

UI-проверка: `node rise/bench/baza/crdttext/playwright/crdttext.js`.
