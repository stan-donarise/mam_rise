# $rise_bench_metrics

Общая таблица последних 100 завершённых локальных операций текущего экрана.
Метрики не сохраняются после F5. Повторная регистрация того же измерения
не дублирует строку. `$rise_bench_measure` создаётся через стабильный wire-task,
поэтому часы не перезапускаются при suspension. `finish()` фиксирует время один раз.

Goods: заполнение товаров, публикация ссылок, индексы, общий путь создания,
добавление товара и ручное перестроение индексов. Общее время включает
подготовку Land; отдельные стадии не включают её. Стадии вложены в общий замер,
поэтому складывать все строки нельзя. Фоновое сохранение и отрисовка не измеряются.
