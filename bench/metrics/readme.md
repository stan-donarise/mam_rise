# $rise_bench_metrics

Таблица прогонов: одна строка на запуск, колонки — отдельные операции.
`runs` содержит реактивные `$rise_bench_run`; `operations` задаёт названия
измерений и единицы в заголовках. `run_add` идемпотентен по identity прогона.
Незавершённые операции показываются как `—`, завершённые — с двумя знаками.
Состояние прогона: выполнение, успешное завершение или ошибка.

Запуск и `$rise_bench_measure` создаются через стабильные wire-task, чтобы
suspension не сбрасывал часы и не создавал дополнительные строки. `finish()`
фиксирует длительность один раз. Промисы не помечаются ошибкой прогона.

Ручные действия не регистрируются. История хранится в текущем экземпляре
экрана, не в Гипербазе; F5 очищает историю, но не тестовые данные.
Вложенные стадии создания входят в общий замер, их нельзя прибавлять к нему.
Фоновое сохранение и отрисовка не измеряются.
