# Rise benchmarks

Все браузерные модули Rise работают с Гипербазой только локально.
`rise.web.ts` отключает итоговый выбор серверов, включая адреса из URL,
начальных настроек и seed-каталога. Сетевой статус не требуется.
`yard.sync()` оставлен: помимо сети он запускает сохранение локальных данных.
IndexedDB и восстановление после F5 продолжают работать.

Проверки не блокируют сеть искусственно: они отклоняют любые сетевые записи
и попытки WebSocket, кроме точного локального MAM hot-reload endpoint.
В URL намеренно указан недоступный master — даже он должен игнорироваться.

```
node rise/bench/baza/goods/playwright/goods-render.js
node rise/bench/baza/crdttext/playwright/crdttext.js
```

Для проверки опубликованного runtime задайте `RISE_TEST_URL`:
`https://stan-donarise.github.io/mam_rise/`. Проверки используют собственные
временные профили браузера и не подключаются к Гипербазе на сервере.
На опубликованной странице тест ждёт штатную активацию service worker и его
первую автоматическую перезагрузку до начала измерений; worker не подменяется.
